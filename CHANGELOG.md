# Changelog

All notable changes to this project are documented here. Version numbers follow [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-21
### Added
- Initial public AI Project Documentation Skill, independent of the private source workflow.
- Agent- and storage-agnostic core in Markdown and JSON.
- Three risk-based documentation profiles: light, professional and critical.
- Handoff, ADR and structured project-state templates.
- Local Python initialization and state validation with unit tests.
- Security, evidence classification, canonical storage and conflict-handling guidance.
- README with installation, usage, testing, and Releases section.

### Known limitations
- No automatic Google Drive, Notion, GitLab, GitHub or other cloud synchronization.
- Agent-specific installation and cross-agent activation not yet validated.
