# v0.1.0 — Initial Public Version

Date: 2026-11-21

## What's included
- Portable AI project documentation skill, agent- and storage-agnostic.
- Evidence-backed handoffs and three documentation profiles.
- Local standard-library Python CLI: initialize documents, validate project state.
- Structured JSON and Markdown templates, security guidance, and storage ownership policy.
- Six regression tests.

## Verification
Run:
```sh
python -m unittest discover -s tests -v
python scripts/pdc.py validate templates/PROJECT-STATE.json
```

## Known limitations
- No automatic cloud provider synchronization.
- Requires an agent that can read skill instructions, and separate tool access to read/write project files.
- GitHub-hosted Release object and downloadable release assets require publication via GitHub Releases; this file alone does not create a GitHub Release.
